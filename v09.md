# V09 — Energy Analytics

**Builds on:** v08  |  **Leads to:** v10

## New Features / Engineering Changes
- Per-machine power (V via tap-safe voltage sensing or estimated from nameplate + current)
- Energy dashboards: kWh/machine/shift, idle-energy detection, idle-cost calculator
- Power-quality lite: sags/swells counter, THD estimate (voltage variant), imbalance from 3 clamps
- ISO 50001-friendly reporting pack

## Engineering Disciplines Most Involved
electrical, industrial, economics

## Tests Added
- Dedicated validation per features above; regression suite must remain green; acceptance: Idle-energy detection validated against utility meter to ±5% on pilot site.

## Exit Criteria
- Idle-energy detection validated against utility meter to ±5% on pilot site.
