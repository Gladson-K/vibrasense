# V06 — Thermal Suite

**Builds on:** v05  |  **Leads to:** v07

## New Features / Engineering Changes
- Contactless IR array (MLX90640) option for hotspot mapping on motor bodies/terminal boxes
- Thermal trend alarms (rate-of-rise), ambient-compensated thresholds
- Motor terminal-box temperature channel (PT100 + MAX31865) variant for critical machines
- Thermal report: weekly per-machine thermal profile PDF

## Engineering Disciplines Most Involved
electrical, materials, mechanical (thermal)

## Tests Added
- Dedicated validation per features above; regression suite must remain green; acceptance: Detect simulated winding insulation degradation (resistive heating) ≥ 1 week before threshold trip.

## Exit Criteria
- Detect simulated winding insulation degradation (resistive heating) ≥ 1 week before threshold trip.
