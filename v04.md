# V04 — Scale & Usability

**Builds on:** v03  |  **Leads to:** v05

## New Features / Engineering Changes
- Multi-language UI (EN/ES/HI/PT) via i18n files
- Fleet onboarding wizard: CSV import, auto-naming, site/machine hierarchy, QR print
- Role-based access (viewer/technician/admin); audit log; SNMP health traps
- SMS/email alerts via gateway (local SMTP + Twilio-equivalent API with on-prem fallback)

## Engineering Disciplines Most Involved
software, human factors, industrial engineering

## Tests Added

## Exit Criteria
