# V02 — Production PCB & Robustness

**Builds on:** v01  |  **Leads to:** v03

## New Features / Engineering Changes
- Custom 2-layer KiCad PCB (MCU + analog front end + power + ESD); external TPS3823 watchdog
- Dual-bank OTA with automatic rollback; signed firmware images
- Boot time < 3 s; brownout-hold testing; extended temp validation (−10 °C)
- Manufacturing test jig v2 (pogo pins, full auto-test, per-unit log to DB)

electronics, manufacturing, embedded
